# designer-skills

Source: [Owl-Listener/designer-skills](https://github.com/Owl-Listener/designer-skills)

This bundle contains 96 nested designer sub-skills organized by category. When
invoked, decide which category matches the task, then read that sub-skill's
`SKILL.md` for detailed guidance.

## Categories

- `design-research/` — user interviews, personas, journey maps, competitive audits.
- `ux-strategy/` — problem framing, opportunity mapping, hypothesis writing.
- `design-systems/` — tokens, component specs, theming, motion systems,
  accessibility audit, localization, naming conventions.
- `interaction-design/` — form design, navigation patterns, feedback patterns,
  loading states, gesture patterns, animation principles, error-handling UX,
  onboarding, search UX, state machines, micro-interaction specs, plus laws
  (Fitts, Hicks, Miller, Doherty).
- `ui-design/` — layout, hierarchy, typography, color, spacing decisions.
- `visual-critique/` — critique color, composition, typography, hierarchy,
  affordance, brand consistency, information density.
- `prototyping-testing/` — prototype fidelity choices, usability test plans.
- `design-ops/` — process, review rituals, handoff, QA.
- `designer-toolkit/` — checklists and templates that plug into the categories above.

## Usage

1. Identify the task's category from the list above.
2. `ls` the category directory, pick the sub-skill whose name matches.
3. Read `<category>/skills/<sub-skill>/SKILL.md` and follow it.
